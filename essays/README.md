# Publicar un ensayo

1. Sube el PDF a esta carpeta con un nombre sencillo, sin espacios ni acentos.
2. Abre `essays.html` en la raíz del repositorio y añade el enlace a la lista, con el ensayo más reciente primero.

```html
<li lang="es"><a href="essays/nombre-del-ensayo.pdf">Título del ensayo</a></li>
```

Para reemplazar un PDF y conservar el enlace, usa el mismo nombre de archivo.
